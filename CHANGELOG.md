# Changelog

## 0.5.0

Initial desktop source baseline recovered from the Windows portable build.

- Electron desktop shell for Windows x64.
- Import of `.tonnage-db` mobile workout databases.
- Export of mobile-compatible `.tonnage` planning packages.
- Separate athlete projects and planning metadata.
- Workout analytics, records, e1RM, streaks, distributions and data-quality checks.
- CSV and PDF export.
- Local offline persistence.
